Mac Color graphics pack for SDLPoP
==================================

This build adds a selectable "Mac Color" graphics pack backed by res_mac_color.pak.
The artwork was decoded from the user-provided Macintosh Prince of Persia disk image,
from its Persia(COLOR) data/resource forks and application CLUT 2000 palette.

Stable pack contents
--------------------
517 graphics entries are replaced with genuine Macintosh COLOR artwork:
- title graphics
- Prince / KID animation frames
- sword, potion and flame graphics
- guards, skeleton, fat guard, shadow and vizier
- princess/chamber sprite groups

The original Mac images are approximately 2x the DOS logical resolution. For this
pack they are reduced 2:1 with nearest-neighbour sampling so SDLPoP can keep its
existing 320x200 logical renderer. Palette index 0 remains transparent.

Dungeon and palace environment SHPD groups are intentionally NOT enabled in the
stable pack. The Macintosh game uses different image dimensions/origins and a
different wall/tile composition model for a number of those resources. Blindly
mapping them produces oversized/misplaced pieces in the DOS renderer.

The companion full experimental PAK replaces 775 matching image IDs, including
those environment groups. It is meant for renderer-port testing, not as the default.

Native source archive
---------------------
The companion Mac-Color-Native-Graphics archive contains all 820 decoded images at
their original Macintosh dimensions, plus manifest.csv with resource IDs and
origin_x/origin_y. Those are the correct source assets for a future true 640x400
Mac renderer mode.
